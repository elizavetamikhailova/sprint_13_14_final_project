# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Проект таск-трекер, позволяет добавлять задания, удалять, изменять и помечать выполненными. 
Из заданий со звездочкой выполнено только аутентификация и докер

Для запуска 
docker build -t sprint_13_14_final_project .
docker compose up -d
в браузере ввести http://localhost:7540/login.html

Для запуска тестов go test ./tests
